## Project Overview

**ColaBot** is an intelligent, context-aware AI chatbot built using
**Meta's Llama 3.3 70B** language model via the **Groq API**.
It can answer questions on programming, data structures, algorithms,
cloud computing, and general knowledge — just like ChatGPT.

This project was built as a mini project to demonstrate the real-world
application of **Natural Language Processing (NLP)** and
**Large Language Models (LLMs)**.


##  Features

- **Multi-turn Conversation** — remembers last 10 exchanges
- **Context-aware Replies** — understands conversation history
- **Code Generation** — writes working code in any language
- **Session Analysis** — visualizes conversation metrics
- **Chat UI** — WhatsApp-style bubble interface in Colab
- **Fast Responses** — powered by Groq's ultra-fast inference
